          NLQ
          
                
          NLQ turns a plain-language question into a read-only DuckDB SELECT, runs it safely, and shows a table or chart.
          
                
          History, filters, and charts stay on the server. The model sees schema and sample values only, never result rows.
          
                
          Stack: FastAPI, DuckDB, vanilla JS, Chart.js, Bootstrap. Bound to localhost via ./bin/start.sh. History retention: Settings → History.
